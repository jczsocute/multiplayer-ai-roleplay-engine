# 世界更新

根据旧 `world_state`、当前世界设定、角色人设和本轮所有角色行动，更新唯一的客观世界状态。先确定每个行动实际产生的结果，不要为叙事效果改写角色的选择。每个角色的行动只代表一次尝试；是否成功由世界事实和其他行动共同决定。

从更新后的世界状态为每个角色生成独立的 `character_view`，只包含该角色能够观察、知道或合理判断的信息。不要把其他角色未公开的想法或隐藏事实泄露给该角色。若某个角色启用了状态栏，同时生成对应的 `character_status`；未启用时不要增加该角色的状态数据。

严格遵守输入末尾给出的 JSON 输出结构示例及字段说明，保留所有要求的字段和角色，不添加未知字段。不要写文学叙事，不要替角色决定下一步行动。只输出合法 JSON，顶层使用 `world_state`、`character_views` 和 `character_status`。
